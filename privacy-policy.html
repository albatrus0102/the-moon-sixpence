독서공방 — 개인정보처리방침

시행일: 2026년 10월 13일 (이전: 2026년 10월 12일)

‘독서공방’(이하 “앱”)은 이용자의 개인정보를 소중히 여깁니다. 이 앱은 독서 기록을 모아두는 서버를 운영하지 않으며, 모든 독서 기록은 기본적으로 이용자의 기기 안에만 저장합니다. 회원가입 없이 사용할 수 있습니다. 다만 책 검색·표지·서지 조회는 개발자가 운영하는 검색 중계 서버를 거쳐 이루어지며, 그 외 일부 선택 기능을 켤 때에도 이용자의 행동으로 데이터가 외부 서비스로 전송됩니다(아래 2항).

1. 기기에 저장되는 정보

  • 독서 기록: 책 제목·저자·표지·진도·별점·무드·날짜·문장·메모·되새김(복습) 카드·독서 시간 등 이용자가 직접 입력한 정보. 기기의 로컬 저장소(localStorage)에만 저장되며, 개발자는 이 데이터에 접근하지 않습니다.
  • 카메라: ISBN 바코드 스캔, 그리고 문장 담기 기능에서 책 페이지를 촬영해 기기 안에서 글자를 인식(OCR)할 때, 그리고 베타 기능 「서가 레이더」·「책장 훑어 담기」에서 책장을 비춰 책등 글자를 기기 안에서 인식할 때 접근합니다. 촬영 이미지는 기기 안에서만 처리되며 저장하거나 외부로 전송하지 않습니다. 「책장 훑어 담기」에서 갤러리의 동영상·사진을 고르는 경우도 안드로이드 사진 선택기로 고른 파일을 기기 안(메모리)에서만 처리하며, 이때 책 검색을 위해 책등에서 인식한 글자(책 제목 외에 저자·출판사 글자가 섞일 수 있으며, 정규화만 거침)가 검색 중계 서버로 전송됩니다. 영상·이미지·썸네일은 전송하지 않습니다(단, AI 카드 자동 생성 기능을 켜고 이미지를 첨부한 경우는 3항의 AI 전송 규칙을 따릅니다).
  • 공유 이미지(사진): 이용자가 ‘독서 카드·문장 공유’ 기능을 실행할 때에만, 공유용 이미지 파일이 기기의 갤러리(사진)에 저장됩니다. 이 이미지는 외부로 자동 전송되지 않으며, 공유 여부·대상은 이용자가 직접 선택합니다.

2. 외부로 전송되는 경우

독서 기록(책·진도·별점·문장·메모 등)은 서버에 저장되지 않지만, 다음 기능을 사용할 때에는 필요한 최소한의 정보가 외부로 전송됩니다.

  • 책 검색·표지·서지 조회: 책을 검색하면 검색어가, 표지·쪽수·출간일·분류·가격 등 서지 정보를 조회할 때는 ISBN이 개발자가 운영하는 검색 중계 서버(Firebase)를 거쳐 카카오 책검색·국립중앙도서관·알라딘 등 외부 도서 정보 서비스로 전달되고, 그 결과가 앱으로 돌아옵니다. 이 중계 서버는 검색어·ISBN을 조회 목적으로만 처리하며, 이용자의 독서 기록이나 개인 식별 정보를 저장하지 않습니다. 중계 서버가 결과를 찾지 못한 경우, 기기가 검색어·ISBN·표지 조회 요청을 Google Books(googleapis.com) 또는 Open Library(openlibrary.org)에 직접 보낼 수 있습니다 — 두 곳 모두 조회 목적으로만 쓰이며 독서 기록이나 개인 식별 정보는 보내지 않습니다.
  • 도서관 이름 검색(‘도서관 대출’ 기능에서 이용할 도서관을 고를 때): 입력한 도서관 이름이 검색 중계 서버를 거쳐 조회되고 결과가 돌아옵니다. 이 조회는 저장되지 않습니다.
  • AI 카드 자동 생성(선택): 이용자가 이 기능을 켜고 본인의 API 키를 입력한 경우에만, 선택한 발췌문·요약 텍스트(및 이용자가 첨부한 파일·이미지가 있으면 그 내용)가 이용자 본인 계정의 외부 AI 서비스로 전송되어 복습 카드로 변환됩니다. 전송 대상은 이용자가 고른 제공자에 따라 Anthropic(Claude, api.anthropic.com) 또는 Google(Gemini, generativelanguage.googleapis.com) 입니다. 사용량·비용은 이용자 본인 API 계정 기준으로 청구됩니다. 첫 사용 전 전송 사실에 동의를 받습니다.
  • 환율 조회(AI 카드 예상 비용 표시용): AI 카드 생성 시 예상 비용을 원화로 안내하기 위해 공개 환율 정보(open.er-api.com)를 조회합니다. 이 요청에는 이용자의 개인정보나 독서 데이터가 포함되지 않습니다.
  • 문의·오류 신고(‘제안하기 → 바로 보내기’): 이용자가 작성한 문의 글과 함께 앱 버전·기기 정보(기기 모델·OS·브라우저 엔진 버전)·앱 언어·최근 오류 기록(오류 메시지·발생 위치)이 개발자가 운영하는 서버로 전송되어 접수 기록으로 보관되고 개발자에게 곧바로 전달됩니다. 답장을 받고 싶어 이메일 주소를 선택으로 입력한 경우 그 주소도 함께 전송됩니다 — 비워 두면 전송되지 않고 답장도 받을 수 없습니다. 독서 기록 내용(책 제목·문장·메모 등)은 담기지 않습니다. 메일 앱으로 직접 보내는 경로를 고르면 이 전송은 일어나지 않고, 이용자의 메일 앱을 통해 곧바로 개발자 메일로 갑니다.
  • 소리로 받아 적기(선택): 문장 담기 화면에서 이용자가 「소리로 받아 적기」를 눌렀을 때에만 마이크를 사용하며, 앱은 소리를 저장하거나 개발자 서버로 보내지 않고 인식된 글자만 문장 칸에 넣습니다. 안드로이드 12 이상이면서 기기 안 음성 인식이 되는 기기에서는 소리가 기기 안에서만 처리됩니다. 그렇지 않은 기기에서는 앱이 먼저 「소리가 인식 서비스로 보내질 수 있다」고 알리고, 이용자가 계속을 고른 경우에만 시작합니다. 이때 소리는 기기에 설치된 음성 인식 서비스(보통 Google)로 전송되어 처리될 수 있으며, 그 처리에는 해당 서비스 제공사의 개인정보처리방침이 적용됩니다.
  • 번역 모델 내려받기(선택): 문장 번역 병기 기능을 쓰려고 이용자가 동의하면, 번역 엔진(Google Play에서 별도 모듈로 내려받음)과 언어별 번역 모델 파일(언어당 약 30MB)을 Google(ML Kit)의 서버에서 한 번 내려받습니다. 이 요청에는 독서 기록이나 문장 내용이 포함되지 않으며, 내려받은 뒤의 언어 판별·번역은 모두 기기 안에서 이루어져 문장이 외부로 전송되지 않습니다.
  • Google ML Kit의 진단 정보: 이 앱은 글자 인식(OCR)·문서 스캔·바코드 스캔·언어 판별·번역·배경 지우기에 Google의 ML Kit를 씁니다. 인식·번역하는 사진과 글 자체는 기기 안에서만 처리되어 외부로 전송되지 않지만, ML Kit는 Google 문서(ML Kit 데이터 공개)에 따라 기능 진단과 사용 분석을 위해 기기 정보(제조사·모델·OS 버전·빌드)·앱 정보(패키지 이름·버전)·성능 지표(처리 지연 등)·오류 코드·설치별 식별자(기능에 따라 기기 식별자 포함)를 Google에 보냅니다(번역·언어 판별은 설정된 언어 정보도 포함). Google은 이 정보를 제3자에게 넘기지 않고 HTTPS로 전송한다고 밝히고 있으며, 이용자의 독서 기록·문장·사진은 포함되지 않습니다. 이 전송은 앱 안에서 따로 끌 수 없습니다. 자세한 내용은 Google의 ML Kit 데이터 공개를 참고하세요.
  • 웹소설 링크 제목 채우기: 서재에 웹소설을 담을 때 붙여넣은 링크(URL)가 제목을 자동으로 채우기 위해 검색 중계 서버로 전달됩니다. 그 서버는 제목을 조회하는 목적으로만 URL을 처리하며 저장하지 않습니다.
  • 오류 자동 수집: 앱이 스스로 잡아낸 오류가 있으면 오류 메시지·오류가 발생한 코드 위치(파일·줄)·앱 버전·앱 언어·기기·브라우저 식별 문자열(User-Agent — 기기·OS·브라우저 엔진 버전이 담긴 표준 식별 문자열)이 자동으로 개발자 서버에 전송될 수 있습니다. 독서 기록 내용(책 제목·문장·메모 등)은 이 전송에 포함되지 않습니다. 설정 → 데이터 관리 → 진단 정보 보내기에서 언제든 끌 수 있습니다(기본은 켜짐).
  • 검색 중계 서버의 접속 기록: 앱이 개발자 중계 서버(Firebase)에 요청을 보낼 때 Google Cloud가 접속 기록(접속 IP 주소·시각·요청 주소·기기/브라우저 식별 문자열)을 자동으로 남기며, Google 정책에 따라 약 30일 보관된 뒤 삭제됩니다. 개발자는 이 기록에서 날짜·시간별 이용자 수와 함께, 접속 IP 주소로 나라 단위로만 추정한 나라별 이용자 수(MaxMind GeoLite2 자료를 서버 안에서만 조회하며, IP 주소를 다른 곳으로 보내지 않습니다)와 기기 언어·앱 화면 언어별 이용자 수를 집계해 서비스 상태 점검에 씁니다. 도시나 정확한 위치는 추정하지 않고, IP 주소를 따로 저장하지 않으며, 저장하는 것은 나라·언어별 인원수뿐입니다. 다음 버전부터 앱이 서버에 요청을 보낼 때 앱 화면 언어 코드(예: ko, en)를 함께 보냅니다(다른 정보는 보내지 않습니다).

3. API 키 처리

AI 카드 자동 생성을 위해 이용자가 직접 입력한 API 키(Anthropic·Google)는 기기에 저장되며, 백업(내보내기) 출력과 동기화에서 제외됩니다. 다만 이용자가 앱을 다시 설치하거나 기기를 바꿨을 때 키를 복원할 수 있도록, 기기에 화면 잠금이 설정된 경우 안드로이드 표준 Block Store를 통해 이용자 본인의 구글 계정에 종단간 암호화된 상태로 보관될 수 있습니다. 이 값은 구글이 관리하는 이용자 계정 영역에 있으며 개발자는 접근할 수 없습니다. 설정에서 키를 지우면 이 보관본도 함께 삭제됩니다. (책 검색·표지·서지 조회는 별도의 키 입력 없이 앱이 기본으로 제공합니다.)

4. 제3자 제공·판매·광고

앱은 이용자의 개인정보를 제3자에게 판매하거나 광고 목적으로 제공하지 않습니다. 광고 SDK와 이용자를 추적하는 분석(트래킹) 도구는 포함하지 않습니다. 다만 위 2항에서 밝힌 대로 Google ML Kit가 기능 진단 목적으로 기기·성능 정보를 Google에 보내며, 이는 광고나 이용자 추적에 쓰이지 않습니다. 위 2항의 외부 서비스 전송은 이용자가 사용하는 기능(검색, AI 카드 등)을 수행하기 위한 것입니다.

5. 권한 안내

  • 인터넷: 책 검색·표지 불러오기, 선택적 AI 카드 생성
  • 카메라: ISBN 바코드 스캔, 문장 담기(페이지 촬영·기기 내 글자 인식), 서가 레이더·책장 훑어 담기(책장 촬영·기기 내 글자 인식, 베타) (사용 시에만, 선택)
  • 알림: 네 가지에 씁니다 — ① 집중 타이머가 목표 시간에 도달했을 때, ② 매주 지난주 독서 리포트가 준비됐을 때, ③ 「달빛 호수」의 내 호수에 새 등불(안부)이 도착했을 때(선택 기능을 켠 경우 — 8-1항 참고), ④ 집중 화면에서 배경 소리를 재생하는 동안 재생 상태를 보여주는 알림. 안드로이드 16 이상에서는 집중 타이머의 진행 알림을 잠금 화면 등에 눈에 띄게 보여 주는 「라이브 업데이트(승격된 진행 알림)」를 쓰며, 이를 위해 승격 알림 게시 권한(POST_PROMOTED_NOTIFICATIONS)을 선언합니다(별도 허용 팝업 없는 일반 권한이고, 정보는 기기 안에서만 만들어집니다). ①·②·④는 내용이 기기 안에서만 만들어지며 외부로 전송되지 않습니다. ③은 다른 이용자가 남긴 등불이 왔음을 알리는 것이라 성격이 다르며, 자세한 내용은 8-1항에 있습니다. 알림은 선택 사항이고 언제든 기기 설정에서 끌 수 있습니다.
  • 캘린더 읽기·쓰기: ‘매일 읽을 시간’을 켜면 이용자가 고른 시각에 기기의 기본 캘린더에 반복 일정을 하나 추가하고, 끄면 그 일정을 지웁니다. 이 목적 외에는 캘린더를 읽거나 쓰지 않으며, 캘린더 내용을 외부로 전송하지 않습니다 (사용 시에만, 선택)
  • 마이크: 문장 담기의 「소리로 받아 적기」를 누른 동안에만 사용합니다. 앱은 소리를 저장하지 않으며, 기기 안 인식이 안 되는 기기에서는 소리가 기기의 음성 인식 서비스로 전송될 수 있습니다(자세한 내용은 2항) (사용 시에만, 선택)
  • NFC: ‘책에 폰 대면 기록 시작’을 켠 경우, 앱이 열려 있는 동안 가까이 댄 NFC 태그의 고유 번호를 읽어 그 책의 기록을 시작합니다. 태그에 쓰지 않으며, 읽은 값은 기기 안에서만 쓰이고 외부로 전송되지 않습니다 (선택)
  • 생체 인증: ‘앱 잠금’에서 지문·얼굴로 여는 방식을 고른 경우에 기기의 표준 인증 화면을 띄우는 데 씁니다. 지문·얼굴 정보는 운영체제가 처리하며 앱은 받지도 저장하지도 않습니다 (선택)
  • 정확한 알람: 집중 타이머 완료 알림을 정해진 시각에 맞춰 울리는 데 씁니다. 이용자가 기기 설정에서 허용한 경우에만 적용되며, 허용하지 않으면 조금 늦게 울릴 수 있습니다 (선택)
  • 부팅 완료 수신: 기기를 다시 켜거나 앱을 업데이트한 뒤 주간 독서 리포트 알림 예약을 다시 걸어 두기 위해서만 씁니다. 다른 용도로 쓰지 않습니다
  • 진동: 버튼을 눌렀을 때·독서를 마쳤을 때 등의 짧은 촉각 반응에 씁니다
  • 배경 소리 재생(포그라운드 서비스): 집중 화면에서 배경 소리를 재생하는 동안, 화면이 꺼져도 소리가 이어지도록 재생 상태 알림과 함께 서비스를 실행합니다 (사용 시에만, 선택)
  • 네트워크 상태 확인: 데이터 절약 모드나 종량제 연결인지 확인해, 그런 때에는 표지 등을 미리 받는 일을 미루는 데 씁니다. 소리 팩이나 번역 모델 파일을 내려받기 전에도 연결 상태를 확인합니다. 연결 정보를 저장하거나 전송하지 않습니다

7. 기기 백업

독서 기록은 원칙대로 이용자의 기기 안에만 저장됩니다. 다만 안드로이드의 기본 백업 기능이 켜져 있으면, 앱이 기기 안에 적어 둔 독서 기록 사본이 이용자 본인의 구글 계정(구글 드라이브)에 저장되어 기기를 바꾸거나 앱을 다시 설치할 때 복원됩니다. 이 사본은 이용자와 구글 사이에서만 오가며, 개발자는 이 사본에 접근할 수 없고 수집하지도 않습니다 — 개발자가 독서 기록을 모아두는 서버가 없다는 1항의 원칙은 그대로입니다. 3항의 API 키는 이 백업(기기 자동 백업)에는 포함되지 않습니다 — 다만 3항에서 설명한 대로, 화면 잠금이 설정된 기기에서는 API 키만 별도의 안드로이드 표준 저장소(Block Store)를 통해 이용자 본인 구글 계정에 종단간 암호화되어 보관될 수 있습니다. 이 백업은 기기의 설정(백업 및 복원)에서 언제든 끌 수 있습니다.

8-1. 달빛 호수(선택 기능)

이용자가 「달빛 호수」에 등불을 띄우기로 한 경우에만, 그 문장(200자 이내)·한 줄 생각·책 제목·저자·쪽·익명 이름·카드 모양·표시 언어가 앱 운영 서버(Firebase, 서울 리전)에 저장되어 다른 이용자에게 익명으로 보입니다. 「이 책을 너에게」로 특정 상대에게 선물을 보낼 때도 같은 서버에 같은 방식(문장·한 줄 생각·책 정보·받는 사람 이름·보내는 사람 익명 이름)으로 저장되며, 이 경우엔 다른 이용자에게 공개되지 않고 전용 링크를 받은 사람만 열람합니다. 계정·연락처는 수집하지 않습니다. 앱은 설치마다 임의의 토큰(64자)을 만들어 기기에 두고 호수·선물 요청에 함께 보내며, 서버는 이 토큰을 해시로만 보관해 본인 여부 확인·하루 게시 횟수 제한·신고 처리에 씁니다(이 토큰은 앱 설치를 구분하는 값이라 앱을 지우면 사라집니다). 다른 이용자의 등불에 남기는 반응(잔물결)과 신고도 이 토큰과 함께 서버에 기록됩니다. 「내 호수」에서 새 등불 도착 알림을 켜면, 알림을 보내기 위한 기기별 알림 토큰(안드로이드 표준 FCM 등록 토큰)이 함께 저장됩니다 — 이용자를 특정하는 연락처가 아니라 알림 발송에만 쓰이는 값이며, 「내 호수」를 닫아도 자동으로 삭제되지는 않으니 삭제를 원하면 9항 문의 채널로 요청할 수 있습니다. 「모두의 호수」 등불은 7일 뒤 자동 삭제되고, 「내 호수」로 받은 등불은 주인이 지울 때까지 보관되며 주인이 호수를 닫거나 등불을 나만 보기로 바꿀 수 있습니다. 이용자는 앱 안에서 자기 게시물을 언제든 삭제할 수 있고, 앱을 지워 토큰을 잃은 경우에는 9항 문의 채널로 게시물 내용을 알려 삭제를 요청할 수 있습니다. 신고가 누적된 게시물은 자동으로 가려지며, 권리자의 삭제 요청도 같은 채널로 접수해 처리합니다. 「내 호수」 링크로 앱 없이 등불을 띄우는 방문자에게도 같은 규칙이 적용되며, 방문자의 IP 주소 해시는 도배 방지 목적으로만 24시간 보관합니다.
