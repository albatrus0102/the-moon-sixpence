달과 6펜스 — 개인정보처리방침

시행일: 2026년 7월 1일

‘달과 6펜스’(이하 “앱”)는 이용자의 개인정보를 소중히 여깁니다. 이 앱은 개발자 서버를 운영하지 않으며, 모든 독서 기록을 기본적으로 이용자의 기기 안에만 저장합니다. 회원가입 없이 사용할 수 있습니다. 일부 선택 기능을 켤 때에만, 이용자의 행동으로 데이터가 외부 서비스로 전송됩니다(아래 2항).

1. 기기에 저장되는 정보

  • 독서 기록: 책 제목·저자·표지·진도·별점·무드·날짜·문장·메모·되새김(복습) 카드·독서 시간 등 이용자가 직접 입력한 정보. 기기의 로컬 저장소(localStorage)에만 저장되며, 개발자는 이 데이터에 접근하지 않습니다.
  • 카메라: ISBN 바코드 스캔 시에만 접근하며, 촬영 이미지를 저장하거나 외부로 전송하지 않습니다.
  • 공유 이미지(사진): 이용자가 ‘독서 카드·문장 공유’ 기능을 실행할 때에만, 공유용 이미지 파일이 기기의 갤러리(사진)에 저장됩니다. 이 이미지는 외부로 자동 전송되지 않으며, 공유 여부·대상은 이용자가 직접 선택합니다.

2. 외부로 전송되는 경우 (선택 기능을 켤 때만)

기본 기능은 모두 오프라인으로 동작합니다. 다음 기능을 사용할 때에만, 해당 외부 서비스로 데이터가 전송됩니다. 모두 이용자의 행동으로 시작되며 개발자 서버를 거치지 않습니다.

  • 책 검색·표지 조회: 입력한 검색어 또는 ISBN이 외부 도서 정보 서비스(Google Books, 카카오 책검색, Open Library, 알라딘, 국립중앙도서관)로 전송되어 책 정보·표지를 받아옵니다. 개인 식별 정보는 전송하지 않습니다.
  • AI 카드 자동 생성(선택): 이용자가 이 기능을 켜고 본인의 API 키를 입력한 경우에만, 선택한 발췌문·요약 텍스트(및 이용자가 첨부한 파일·이미지가 있으면 그 내용)가 이용자 본인 계정의 외부 AI 서비스로 전송되어 복습 카드로 변환됩니다. 전송 대상은 이용자가 고른 제공자에 따라 Anthropic(Claude, api.anthropic.com) 또는 Google(Gemini, generativelanguage.googleapis.com) 입니다. 사용량·비용은 이용자 본인 API 계정 기준으로 청구됩니다. 첫 사용 전 전송 사실에 동의를 받습니다.
  • 환율 조회(AI 카드 예상 비용 표시용): AI 카드 생성 시 예상 비용을 원화로 안내하기 위해 공개 환율 정보(open.er-api.com)를 조회합니다. 이 요청에는 이용자의 개인정보나 독서 데이터가 포함되지 않습니다.

3. API 키 처리

이용자가 입력한 API 키(Anthropic·Google·알라딘·카카오 등)는 기기 안에만 저장되며, 백업(내보내기) 출력에서 제외됩니다. 개발자는 키를 수집·저장하지 않습니다.

4. 제3자 제공·판매·광고

앱은 이용자의 개인정보를 제3자에게 판매하거나 광고 목적으로 제공하지 않습니다. 광고 SDK·분석(트래킹) 도구를 포함하지 않습니다. 위 2항의 외부 서비스 전송은 이용자가 켠 기능을 수행하기 위한 것입니다.

5. 권한 안내

  • 인터넷: 책 검색·표지 불러오기, 선택적 AI 카드 생성
  • 카메라: ISBN 바코드 스캔 (스캔 시에만 사용, 선택)

6. 데이터 보관 및 삭제

로컬 데이터는 ‘설정 → 모든 기록 초기화’를 실행하거나 앱을 삭제하면 즉시 삭제됩니다. 입력한 API 키는 설정에서 비우면 삭제됩니다. 자세한 절차는 데이터 삭제 안내를 참고하세요.

7. 아동의 개인정보

앱은 만 14세 미만 아동을 주요 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.
