독서공방 — 데이터 삭제 안내

시행일: 2026년 6월 29일

독서공방은 독서 기록을 모아두는 서버나 계정을 운영하지 않습니다. 모든 독서 기록은 이용자의 기기 안에만 저장됩니다. (책 검색·표지 조회는 개발자가 운영하는 검색 중계 서버를 거치지만, 이 서버는 검색어·ISBN을 조회 목적으로만 처리할 뿐 독서 기록을 저장하지 않습니다.) 따라서 독서 기록의 삭제는 전적으로 이용자가 직접, 즉시 할 수 있습니다.

1. 모든 기록 삭제 (앱 내)

  • 설정 → 모든 기록 초기화: 이 기기의 모든 독서 기록·되새김 카드·통계가 즉시 삭제됩니다.
  • 또는 안드로이드 설정 → 애플리케이션 → 독서공방 → 저장공간 → 데이터 삭제, 혹은 앱 제거로도 모든 데이터가 삭제됩니다.

2. API 키 삭제

AI 카드 자동 생성을 위해 입력한 API 키는 설정에서 해당 입력칸을 비우고 저장하면 기기에서 삭제됩니다. 키는 외부로 전송·저장되지 않으므로 추가 절차가 필요 없습니다. (책 검색·표지 조회는 별도의 키 입력이 없습니다.)

3. 백업 파일 삭제

‘내보내기’로 만든 JSON 백업 파일이 있다면, 해당 파일을 직접 삭제하세요.
